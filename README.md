## Featured Projects

- **[Lung Cancer Detection AI](https://github.com/davinmaritza/lung-cancer-detection-ai)**  
  A hybrid computer vision system for pulmonary nodule malignancy classification from thoracic CT scans. Combines deep CNN feature extraction with classical classifiers (XGBoost & Random Forest) alongside Grad-CAM visual explainability.

- **[Multimodal Medical Imaging Pipeline](https://github.com/davinmaritza)**  
  An end-to-end deep learning pipeline for brain tumor segmentation and classification using the BraTS dataset. Deployed with a lightweight FastAPI inference service and Grad-CAM interpretability for medical imaging workflows.

- **Phantomic VPS Control Panel**  
  A Next.js virtualization dashboard built on the Proxmox VE REST API. Enables users to provision, monitor, and manage virtual machines with an integrated browser-based noVNC WebSocket console.

- **[Pterodactyl Espresso Theme](https://github.com/davinmaritza/pterodactyl-espresso-theme)**  
  An open-source dark minimalist theme engineered for Pterodactyl Panel v1.11.x game server management infrastructure.
