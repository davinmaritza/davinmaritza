## About Me

I'm Davin — 10th grader in the Software Engineering (RPL) program at SMKN 13 Bandung by day, and running infrastructure by night. Officially still a student, unofficially running payroll for a hosting company.

I founded **ByteNodes**, a VPS and game server hosting provider, where I mostly sit on the finance and HR side while the technical team keeps the servers alive. On top of that I work as Network Head Officer at Phantomic Host, and I've got a soft spot for DevOps work in general — automation, deployments, keeping infra from falling over. Somewhere in between all of that I still find time to mess with home server setups, scripts, and the occasional Minecraft plugin.

What I actually enjoy is the mix — one hour I'm reading a balance sheet, the next I'm debugging a Proxmox cluster. It shouldn't work, but somehow it does.
